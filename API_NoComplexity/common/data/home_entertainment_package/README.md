# Home Entertainment Package
**Domain Combination**: SmartHomeEnv + MediaControlEnv + InformationControlEnv  
**Total Tools**: 47 tools (19 + 16 + 12)

## Description
This package combines smart home control, media entertainment, and information retrieval for comprehensive home entertainment scenarios. Perfect for testing weather-responsive entertainment setups, automated home theater configurations, and contextual media recommendations.

## Included Data Files

### SmartHomeEnv (19 tools)
- `devices_expanded.json` - Smart home devices (lights, thermostats, locks, etc.)
- `groups_expanded.json` - Device groupings and room configurations

### MediaControlEnv (16 tools)
- `media_database_expanded.json` - Movies, TV shows, music, streaming services
- `media_expanded.json` - Media content metadata
- `playlists_expanded.json` - User playlists and preferences

### InformationControlEnv (12 tools)
- `mock_data_expanded.json` - Weather, news, stocks, knowledge base
- `info_expanded.json` - Information sources and data
- `sources_expanded.json` - Data source configurations
- `queries_expanded.json` - User query history and patterns

### Core Data
- `users_expanded.json` - User profiles and preferences

## Example Use Cases
- Movie night preparation with weather-based comfort adjustments
- Morning routine with news briefing and home automation
- Weather-responsive entertainment and lighting preferences
- Contextual media recommendations based on environmental conditions
