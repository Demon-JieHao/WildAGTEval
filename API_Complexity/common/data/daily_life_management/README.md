# Daily Life Management
**Domain Combination**: SmartHomeEnv + TimeNotificationEnv + InformationControlEnv  
**Total Tools**: 39 tools (19 + 8 + 12)

## Description
This package focuses on intelligent daily routine automation with temporal reasoning. It combines smart home control with time-based notifications and information services for proactive life management scenarios.

## Included Data Files

### SmartHomeEnv (19 tools)
- `devices_expanded.json` - Smart home devices (lights, thermostats, locks, etc.)
- `groups_expanded.json` - Device groupings and room configurations

### TimeNotificationEnv (8 tools)
- `notifications_expanded.json` - System notifications and alerts
- `reminders_expanded.json` - User reminders and scheduled tasks
- `alarms_expanded.json` - Alarm settings and schedules

### InformationControlEnv (12 tools)
- `mock_data_expanded.json` - Weather, news, stocks, knowledge base
- `info_expanded.json` - Information sources and data
- `sources_expanded.json` - Data source configurations
- `queries_expanded.json` - User query history and patterns

### Core Data
- `users_expanded.json` - User profiles and preferences

## Example Use Cases
- Smart morning routines based on weather and calendar
- Energy-efficient home automation with scheduled adjustments
- Weather-aware reminder scheduling and home preparation
- Proactive environmental control based on daily patterns
- Intelligent wake-up sequences with information briefings
